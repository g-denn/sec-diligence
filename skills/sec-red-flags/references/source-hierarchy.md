# Source hierarchy

Use sources in this order for proof. A lower source can help discover a filing, but cannot replace an accessible higher source.

1. SEC EDGAR filing text, XBRL facts, filing index, and official SEC orders.
2. Issuer-filed or issuer-hosted copies that match the SEC filing, investor-relations releases, and official transaction documents.
3. Exchange or other official regulator notices, where applicable.
4. Reputable secondary reporting, only to locate primary evidence or frame a clearly labeled open question.

For every material item, preserve enough provenance to re-find it: issuer/CIK, form, filing date, reporting period, accession or stable URL, and section/item/page. Add the ledger cutoff date separately; a filing date is not automatically the analysis cutoff.

If a source conflicts with a later amendment, identify both and treat the amendment as controlling for the amended disclosure. If the conflict cannot be resolved, report it as an unknown with both citations.
