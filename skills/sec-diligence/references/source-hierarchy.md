# Source hierarchy

Use sources in this order for proof. A lower source can help discover a filing, but cannot replace an accessible higher source.

1. SEC EDGAR filing text, XBRL facts, filing index, and official SEC orders.
2. Issuer-hosted copies that match an SEC filing, plus official transaction documents filed with the SEC.
3. Exchange or other official regulator notices, where applicable.
4. Issuer releases that are not filed, as contextual company statements rather than proof of a filed fact.
5. Reputable secondary reporting, only to locate primary evidence or frame a clearly labeled open question.

For every material item, preserve enough provenance to re-find it: issuer/CIK, form, filing date, SEC accepted timestamp, reporting period, accession or stable URL, and section/item/page. Add the ledger cutoff date separately; a filing date is not automatically the analysis cutoff.

Respect the requested cutoff using the SEC accepted timestamp. For a current review, identify both an original filing and a later amendment and treat the amendment as controlling for the amended disclosure. For a historical review, do not import an amendment accepted after the cutoff into the historical evidence set; mention it only as clearly labeled post-cutoff context when requested. If an in-scope conflict cannot be resolved, report it as an unknown with both citations.
